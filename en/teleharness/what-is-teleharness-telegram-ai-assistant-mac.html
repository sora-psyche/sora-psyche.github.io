1. What Is Teleharness? Unofficial macOS Telegram AI Build Explained

Teleharness is the internal name surfaced in independent November 2026 technical reports describing an unofficial, unconfirmed experimental macOS build of Telegram with a built-in operating-system-level AI agent. Unlike conventional chat bots that only respond to text inside a single thread, this experimental desktop agent interacts with the full messenger interface and local workspace—reading dialogs, inspecting interface elements, organizing folders, and executing multi-step tasks autonomously.

The build follows a strict Bring Your Own Key (BYOK) model: users connect their own API keys or local model endpoints (such as Claude, ChatGPT, or Codex-compatible models) rather than relying on a bundled cloud subscription. Everything runs locally through the macOS client and its companion virtual environment, making it an intriguing case study in how desktop messengers are evolving into agentic operating systems.

2. 16 Tool Groups & 303 Built-In Native Commands

According to the 14 technical sources analyzed in our video explainer, the agent organizes its capabilities into 16 distinct tool groups comprising 303 built-in tools. These cover dialog management, search, drafts, folders, voice calls, Telegram Stars, storage cleanup, and live interface control. Three standout low-level tools highlight its depth:

  • ui_snapshot — reads the macOS Accessibility tree (the same structure used by macOS VoiceOver) so the agent can inspect on-screen buttons, lists, and active windows without blind coordinate guessing.
  • mini_app_script — injects and executes JavaScript directly inside Telegram Mini Apps (WebApps) to automate interactive web views.
  • download_control — monitors local disk usage and pauses, resumes, or cancels active media downloads in real time.

3. 28 Markdown (.md) Plugins: Linux VM Sandbox vs. Gated Mac MCPs

Instead of compiled binary extensions, Teleharness defines its 28 plugins as plain Markdown (.md) files. When a user drops a plugin Markdown specification into a chat, the agent parses the instructions and routes execution into one of two isolated tiers:

  • VM Plugins (Default Sandbox): Executed via Bash inside a dedicated, isolated Linux virtual machine on the Mac. All setup scripts are required to be strictly idempotent so repeated runs never corrupt state.
  • MCP Plugins (Host macOS Server): Model Context Protocol servers that interact directly with native macOS applications (such as Calendar, Reminders, or browser automation) and therefore pause for explicit user approval before installation.

4. Strict Safety Gate (Allow / Ask / Never) & Real Mac Speed Benchmarks

To prevent unintended actions, the runtime enforces a three-tier permission matrix (Allow, Ask, Never) and stores API credentials in a separate .env vault outside the Markdown plugin files. Any operation that costs money, publishes, sends, or deletes triggers a mandatory confirmation prompt—even when the assistant is set to full access mode. In timed November 2026 macOS benchmarks, the agent scanned and summarized 5 unread dialogues in 32 seconds and generated a complete multi-sheet Excel budget from raw notes in 1 minute 36 seconds.
